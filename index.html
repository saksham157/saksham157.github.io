SEV-2 · Kubernetes

A pod that crashed with no error in its logs

Cause: the app was a script that exited, so Kubernetes restarted it forever. Fixing it exposed a Service port mismatch and an image missing Flask. Lesson: CI and the image must install from the same source.

SEV-2 · Jenkins

A green build where nothing ran

Cause: the library step was called without parentheses, so Groovy skipped the pipeline body. Lesson: check that stages ran, not only the colour.

SEV-3 · PostgreSQL

A config change that never applied

Cause: the listen address line was still commented out. Lesson: verify the running process, not the file.

SEV-3 · GitOps

Helm values that never reached Git

Cause: the stage assumed the GitOps repo was already cloned, and sed broke on nested quotes. Lesson: make every pipeline step self-contained.
